# Методология denoise-эксперимента

## Цель

Проверить, насколько модель шумоподавления улучшает русскую речь, не зная исходного ответа заранее. Для этого мы не оцениваем модель на случайных «грязных» записях: сначала берём чистую речь, добавляем к ней известный реальный шум, затем сравниваем результат модели с исходной чистой дорожкой.

```text
clean.wav + noise.wav -> noisy.wav -> denoise model -> enhanced.wav
       ^-----------------------------------------------^
                  known ground truth for comparison
```

## Данные

### Чистая речь

Источник: M-AILABS Russian (`data/raw/m_ailabs_ru/`).

После индексации в корпусе 20 499 WAV-клипов. Клипами одной книги нельзя случайно делить train и test: соседние фразы слишком похожи, и метрика получится оптимистичнее реального результата.

### Разбиение

Разбиение делается по целой аудиокниге скриптом:

```powershell
python scripts/split_m_ailabs.py
```

Текущий seed создаёт:

| Split | Число клипов | Назначение |
|---|---:|---|
| `train` | 17 088 | Позже: fine-tune модели |
| `dev` | 2 387 | Подбор параметров и проверка в ходе разработки |
| `test` | 1 024 | Финальная замороженная оценка |

`test` не меняется после того, как будут выбраны параметры модели. Дикторы, представленные только одной книгой, остаются в train, чтобы первая версия обучения содержала и мужские, и женский голоса.

### Шум

Основной источник: MUSAN, папка `musan/noise/` после распаковки архива. В первую версию не добавляем `musan/music` и `musan/speech`: цель — сначала оценить подавление фонового шума, а не разделение голосов или музыки.

Позже нужно добавить отдельный real-world test: телефонные записи комнаты, улицы, транспорта и разговорного пространства. Эти записи не смешиваются с тренировочными шумами.

## Синтез noisy-clean пар

Генератор:

```powershell
.\.venv\Scripts\python.exe -m pip install soundfile
python scripts/make_noisy_pairs.py --noise-dir data\raw\musan\musan\noise
```

По умолчанию он создаёт 100 тестовых пар из `test` split. Для каждой пары:

1. Выбирается чистая фраза `clean.wav`.
2. Выбирается случайный WAV-шум и случайный временной отрезок нужной длины.
3. Шум масштабируется до случайного SNR: 0, 5 или 10 dB.
4. Создаётся `noisy.wav = clean.wav + scaled_noise.wav`.
5. При необходимости вся тройка масштабируется одинаково, чтобы избежать клиппинга.

Для каждой пары сохраняются:

```text
data/derived/denoise_eval/
  clean/<id>.wav
  noise/<id>.wav
  noisy/<id>.wav
  manifest.csv
```

`manifest.csv` содержит исходный clean-клип, исходный noise-файл и фактический SNR. Это позволяет повторить любой пример и объяснить любую цифру в таблице.

## Первое сравнение модели

Нужно сравнить не одну, а три дорожки:

```text
clean.wav      эталон
noisy.wav      вход / baseline
enhanced.wav   результат модели
```

Порядок работы:

1. Прогнать все `noisy.wav` через текущий DeepFilterNet без дообучения.
2. Посчитать метрику `SI-SDR` для `noisy` относительно `clean` и для `enhanced` относительно `clean`.
3. Посчитать `ΔSI-SDR = SI-SDR(enhanced, clean) - SI-SDR(noisy, clean)`.
4. Прослушать минимум 10 случайных примеров на каждом SNR. Отдельно отмечать съеденные согласные, металлические артефакты, изменение тембра и обрыв хвостов слов.

Положительный `ΔSI-SDR` означает, что модель приблизила сигнал к эталону. Одной метрики недостаточно: качество речи оценивается также слушанием.

## После baseline

Только если baseline заметно слаб на русской речи или на нужном типе шума, начинается fine-tune.

Для fine-tune:

- использовать только `train`;
- выбирать `dev` для настройки числа эпох и других параметров;
- ни разу не использовать `test` для обучения, выбора параметров или отбора удачных аудиопримеров;
- после обучения повторить тот же скрипт оценки на том же test-наборе;
- сравнить original DeepFilterNet и Russian fine-tuned DeepFilterNet на одинаковых noisy-файлах.

## Границы первого эксперимента

Первая итерация оценивает **русскую речь + фоновый шум**. Пение, вокал в музыкальном миксе, реверберация и одновременная речь нескольких людей будут отдельными экспериментами: для них нужны дополнительные датасеты и отдельные выводы.
