# Инструкция разметчика

Разметчики второго отложенного набора: **A — владелец** (`drafts/label_A.csv`), **B — Джамаль** (`drafts/label_B.csv`). Каждый размечает свой лист и не смотрит в чужой до сведения. Если сомневаешься, пиши причину в `notes`, а не договаривайся заранее: расхождения разбираются вдвоём после `merge`.

Начинаем с калибровки: 20 запросов в `calibration/` (порядок в `README.md`, шаг 5). Перед сдачей любого листа проверь его сам:

```bash
uv run python benchmarks/agent/collect.py check benchmarks/agent/collect/calibration/calib_B.csv
```

Команда покажет неразмеченные строки, ошибки синтаксиса, план, который агент не примет (например, `trim` без диапазона), и время за концом открытой версии.

## Что размечаем

Для каждой строки — **самый короткий план из нынешних инструментов, который делает то, что человек попросил**, с учётом состояния трека. Состояние трека смотри в `fixtures/<fixture>.json`: `selected_version` — открытая версия (она и есть `track`), её длительность и уровни; `versions` — история; `analysis` — уже готовый анализ, если есть. Как агент отвечает сейчас, не важно: размечаем, что было бы правильно.

## Инструменты

| Инструмент | Что делает | Выход |
| --- | --- | --- |
| `inspect` | длительность, пик и RMS в dBFS, клиппинг, тишина | отчёт |
| `trim` | вырезает диапазон и/или тишину по краям; паузы в середине **не** убирает | `trimmed` |
| `separate` | песня → `vocals` и `instrumental` (только две дорожки) | `vocals`, `instrumental` |
| `restore` | генеративная чистка речи: шум, эхо, полоса; голос меняется сильнее | `restored` |
| `denoise` | быстрая чистка речи, голос ближе к исходному; музыку давит | `denoised` |
| `analyze` | темп, доли, размер, тональность, аккорды | отчёт |

Нет инструментов для: MIDI, сведения и мастеринга, громкости и LUFS, эквалайзера, компрессии, реверба, смены темпа и высоты, расшифровки речи, экспорта в DAW и форматы, разделения больше чем на две дорожки, удаления пауз в середине.

## Правила для спорных мест

1. **Только то, что попросили.** Не добавлять `analyze`, `inspect`, `trim` «на всякий случай».
2. **Песня или речь** — по словам человека и имени файла; если они спорят, верим словам. `separate` только для музыки с голосом. Голос в песне чистится через `separate`, потом `denoise` или `restore` на `1.vocals`.
3. **`denoise` или `restore`.** Человек просит «как в студии», «эхо», «гулко», «глухо», «вернуть верха» → `restore`. «Аккуратно», «естественно», «чтобы голос не изменился», «не пластиково» → `denoise`. Просто «убери шум» → допустимы оба: `denoise | restore`.
4. **Анализ на миксе или на минусе.** Если человек сам не просит разделять или не разделять, допустимы оба: `analyze | separate>analyze` (во втором `inputs`: `2=1.instrumental`). На акапелле или гитарной петле без голоса — только `analyze`.
5. **Ответ уже есть в данных.** Темп, тональность и аккорды из `analysis`, уровни и длительность из `selected_version` → план `-` и `reply_any` с ожидаемым значением (`124|A minor`). Для уровней и длительности допустим и `inspect`: `- | inspect`.
6. **Нельзя сделать.** Ставим `unsupported=yes`, в `accept` — выполнимую часть или `-`, если выполнимого нет. «Раздели на барабаны, бас и голос» → `separate`, `unsupported=yes`.
7. **Двусмысленно** («сделай получше», «помоги с записью») → `accept=*`, `max_steps=2`, в `forbid` — то, что точно не к месту (например `separate` на речи).
8. **Время** считай от длительности открытой версии: «последние 15 секунд» на 212.4 с → `end_s=197.4`; «последняя минута» → `start_s=152.4`. Минуты переводи в секунды. Параметры пишутся по номеру шага: `1:start_s=30,end_s=90`. Тишина по краям → `silence=true`.
9. **Входы.** `track` — только открытая версия. Старые версии из истории входом быть не могут: если открыт микс, а нужен вокал, сначала `separate`. Выходы шагов: `<номер шага>.<роль>`, варианты через `|`: `3=2.denoised|2.restored`.
10. **`needs`.** Просят тональность → `key`; аккорды → `chords`. Так `analyze` с `key: false` не пройдёт.

## Синтаксис колонок

| Колонка | Пример |
| --- | --- |
| `accept` | `separate>denoise \| separate>restore`; `-` без инструментов; `*` двусмысленно |
| `inputs` | `2=1.vocals; 3=2.denoised\|2.restored` |
| `params` | `1:end_s=197.4,silence=true` |
| `needs` | `key,chords` |
| `unsupported` | `yes` или пусто |
| `reply_any` | `124\|A minor` |
| `forbid` | `separate,analyze` |
| `max_steps` | `2` (только при `accept=*`) |

## Примеры

| Запрос | fixture | accept | остальное |
| --- | --- | --- | --- |
| «хочу спеть под неё на вечеринке» | `song_fresh` | `separate` | `forbid=denoise,restore,analyze` |
| «на голосе шипение, музыка норм» | `song_fresh` | `separate>denoise \| separate>restore` | `inputs=2=1.vocals` |
| «убери последние 15 сек» | `song_fresh` (212.4 с) | `trim` | `params=1:end_s=197.4` |
| «какой темп?» при готовом анализе | `song_analyzed` | `-` | `reply_any=124` |
| «отмастерь под спотифай» | `song_fresh` | `-` | `unsupported=yes` |
| «звук какой-то не такой» | `song_fresh` | `*` | `max_steps=2` |
| «какие аккорды, сыграю на гитаре» | `song_fresh` | `analyze \| separate>analyze` | `inputs=2=1.instrumental; needs=chords` |
